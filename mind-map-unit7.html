الدرس الأول
الانتروبي — Entropy (S)
🌪️
تعريف الانتروبي والتلقائية ▼
  • التلقائية: حدوث التفاعل بشكل طبيعي بدون تأثير خارجي
  • الانتروبي S: مقياس درجة العشوائية الموجودة في النظام
  • بعض العمليات تحدث في اتجاه واحد ولا يمكن أن تنعكس
  • ΔS = + عند زيادة العشوائية (من النظام إلى الفوضى)
  • ΔS = − عند نقص العشوائية (من الفوضى إلى النظام)
  • النظام يفضل المحتوى الحراري المنخفض ΔH = −ve
  • النظام يفضل الانتروبي المرتفع ΔS = +ve
📊
العوامل التي تزيد الانتروبي ▼
  • ① تغيّر الحالة الفيزيائية:
  • مو(s) < مو(l) < مو(g) — ΔS: صلب→سائل→غاز = تزداد عشوائية
  • عمليات تزيد S: الانصهار — التبخر — التسامي → ΔS = +
  • عمليات تقلل S: التجمد — التكثف — الترسيب → ΔS = −
  • ② زيادة عدد الجسيمات (المولات): نواتج أكثر مولات → ΔS = +
  • ③ زيادة درجة الحرارة: تزداد الطاقة الحركية → تزداد سرعة الجسيمات → ΔS = +
  • ④ زيادة تركيز المواد المذابة كلياً: يزداد عدد الجسيمات في النواتج → ΔS = +
  • ⑤ زيادة حجم الغاز: تزداد المسافة بين الجزيئات → ΔS = +
🔬
كيف تحدد إشارة ΔS من المعادلة؟ ▼
  • خطوة 1: قارن مولات الغاز في النواتج والمتفاعلات
  • مولات غاز النواتج > المتفاعلات → ΔS = + (تزداد)
  • مولات غاز النواتج < المتفاعلات → ΔS = − (تقل)
  • خطوة 2: إذا تساوت مولات الغاز → انظر لتغيّر الحالة الفيزيائية
  • صلب/سائل → غاز = ΔS = + | غاز → صلب/سائل = ΔS = −
  • خطوة 3: انظر عدد الجسيمات الذائبة (aq) — أكثر في النواتج = ΔS = +
  • ⚠️ إذا صعب التحديد → "يصعب توقع التغير في الانتروبي"
الدرس الثاني
تغيرات الانتروبي في التفاعلات الكيميائية
🌡️
الانتروبي المطلق S° والقانون الثالث ▼
  • الانتروبي المطلق القياسي S°: التغير في الانتروبي بين درجة الصفر المطلق (0K) وحرارة ثلاث لثلاث المادة (298K)
  • القانون الثالث للديناميكا الحرارية: الصفر المطلق هو أدنى درجة حرارة ممكنة — عندها الانتروبي للنظام يساوي صفراً
  • عند T = 0K → النظام في حالة نظام مثالي → انتروبي = صفر
  • عند T > 0K → النظام أكثر عشوائية → انتروبي موجب
  • وحدة قياس S°: J/mol·K
  • العناصر النقية لها إنتروبي قياسي S° موجبة (رغم أن ΔH°f = 0)
  • الحالة الفيزيائية لها تأثير كبير في قيمة S° المطلقة
  • مثال: Fe(s) = 27.15 J/mol·K | Fe(g) = 180.5 J/mol·K
🧮
حساب ΔS° للتفاعل ▼
  • ΔS° = Σ(n × S°نواتج) − Σ(m × S°متفاعلات)
  • n, m = معاملات المعادلة الموزونة
  • ΔS° موجبة (+) → انتروبي النواتج > المتفاعلات → زيادة في الانتروبي
  • ΔS° سالبة (−) → انتروبي النواتج < المتفاعلات → نقصان في الانتروبي
  • ⚠️ لا يمكن حساب المحتوى الحراري H° مطلقاً — لكن يمكن حساب ΔH°
  • يمكن حساب S° مطلقاً (بفضل القانون الثالث) وأيضاً ΔS°
  • يمكن حساب ΔS° بطريقة هس أيضاً (جمع معادلات)
💡
أمثلة تطبيقية على ΔS ▼
  • 2NH₄NO₃(s) → 2N₂ + 4H₂O(l) + O₂ → ΔS = + (صلب → غاز)
  • 8SO₂(g) + 16H₂S(g) → 3S₈(s) + 16H₂O → ΔS = − (غاز → صلب)
  • 4Fe(s) + 3O₂(g) → 2Fe₂O₃(s) → ΔS = − (غاز → صلب + تقليل مولات)
  • CaCO₃(s) → CaO(s) + CO₂(g) → ΔS = + (صلب → غاز)
  • C₁₂H₂₂O₁₁(aq) + H₂O → 2C₆H₁₂O₆(aq) → ΔS = + (جسيمات ذائبة أكثر)
الدرس الثالث
طاقة جبس الحرة — Gibbs Free Energy (G)
⚡
تعريف طاقة جبس وقانونها ▼
  • أقصى كمية من الشغل يمكن الحصول عليها من نظام مغلق
  • وحدتها: الجول (J) أو كيلوجول (kJ)
  • ΔG° = ΔH° − T × ΔS°
  • ⚠️ T بالكلفن: T(K) = T(°C) + 273
  • ⚠️ وحّد الوحدات: إذا ΔH بالـ kJ وΔS بالـ J → اقسم ΔS على 1000
  • ΔG° سالبة (−) → التفاعل تلقائي
  • ΔG° موجبة (+) → التفاعل غير تلقائي
  • ΔG° = صفر → النظام في حالة اتزان (لا يميل لأي اتجاه)
📋
جدول الحالات الأربعة للتلقائية ▼
ΔH°ΔS°ΔG°التلقائية
− (طارد) + (يزداد) سالبة دائماً ✅ تلقائي عند كل درجات الحرارة
+ (ماص) − (يقل) موجبة دائماً ❌ غير تلقائي عند كل درجات الحرارة
+ (ماص) + (يزداد) تعتمد على T ✅ تلقائي عند درجات الحرارة العالية فقط
− (طارد) − (يقل) تعتمد على T ✅ تلقائي عند درجات الحرارة المنخفضة فقط
🔗
الطاقة الحرة والاتزان ▼
  • ΔG < 0 → يسير التفاعل الانعكاسي في الاتجاه الطردي (متفاعلات → نواتج)
  • ΔG > 0 → يسير التفاعل الانعكاسي في الاتجاه العكسي (نواتج → متفاعلات)
  • ΔG = 0 → النظام في حالة اتزان (لا يميل للطردي أو العكسي)
  • عند نقطة الاتزان: T = ΔH / ΔS
  • مثال: C₆H₆(l) ⇌ C₆H₆(s) عند ΔG=0 → T = −9.83/(−0.0352) = 279.26 K = 6.26°C
🧮
أنواع مسائل ΔG وخطوات الحل ▼
  • نوع A — يُعطى ΔH° وΔS°:
  • ① حوّل T إلى كلفن | ② حوّل ΔS إلى kJ/mol·K (÷1000) | ③ عوّض في ΔG = ΔH − TΔS
  • نوع B — يُعطى جدول S° وΔH°f:
  • ① احسب ΔH° = Σ(n×ΔH°f نواتج) − Σ(m×ΔH°f متفاعلات)
  • ② احسب ΔS° = Σ(n×S° نواتج) − Σ(m×S° متفاعلات) | ③ عوّض في ΔG
  • نوع C — إيجاد T عند الاتزان (ΔG = 0):
  • T = ΔH / ΔS (بعد توحيد الوحدات)
  • نوع D — إيجاد ΔS عند الاتزان:
  • ΔS = ΔH / T
⚠️
نقاط مهمة وأخطاء شائعة ▼
  • ⚠️ دائماً T بالكلفن في معادلة ΔG = ΔH − TΔS
  • ⚠️ وحدة ΔG = kJ/mol | وحدة ΔS = J/mol·K — لا بد من التوحيد
  • ⚠️ S° للعناصر النقية ≠ صفر (خلافاً لـ ΔH°f التي = صفر)
  • ⚠️ التلقائية لا تعني السرعة — التفاعل قد يكون تلقائياً ولكن بطيئاً جداً
  • التفاعلات التلقائية: تحدث بمجرد إتمامها التام (قد تكون سريعة أو بطيئة)
  • العوامل التي تحدد التلقائية: ① المحتوى الحراري ② الانتروبي ③ درجة الحرارة المطلقة
  • ΔG يمكن حسابها أيضاً من: ΔG°r = Σ(n×ΔG°f نواتج) − Σ(m×ΔG°f متفاعلات)
